## Konstruktor dengan variabel panjang dan lebar
def __init__(self, panjang, lebar):
        self.panjang = panjang
        self.lebar = lebar

`*` def hitung keliling dan luas adalah metode untuk menghitung keliling dan luas dengan parameter self agar bisa mengakses variabel.

`*` def str adalah fungsi untuk menampilkan string objectnya. huruf f didepan tanda kutip fungsinya untuk mempermudah memasukkan variabel ke dalam teks
